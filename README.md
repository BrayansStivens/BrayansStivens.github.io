# brayansstivens.github.io

Portfolio personal con estética de consola. HTML, CSS y JavaScript sin dependencias ni build: GitHub Pages lo sirve tal cual desde `main`.

Dos vistas:

- **perfil** (por defecto): todo el contenido visible, pensado para quien no es técnico.
- **terminal** (`/#terminal` o Ctrl+K): una shell con `ls`, `cd`, `cat`, `open`, autocompletado con Tab e historial.

Archivos:

- Contenido en español e inglés: objeto `T` en `main.js`.
- Sistema de archivos de la terminal: `FILES` en `main.js`.
- Estilos y paleta: `styles.css`.

Probar en local: `python3 -m http.server 8000` y abrir http://localhost:8000.
